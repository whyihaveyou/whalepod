## QA 逐项（矢量稿 vs 参考图）

1. **构图**：四鲸环形 + 90° 旋转对称是否还原；中心负空间风车是否成立；鲸群是否居中且与 tile 边距均衡。
2. **姿态**：鲸体弧曲方向、尾鳍外撇、鳍部数量/位置；四鲸是否同形同节奏（生成图四鲸近似同形旋转，重绘应保持）。
3. **色彩**：白→青渐变方向与高光位置；深蓝投影块有无；tile 蓝渐变色相/明度；两处圆形水影是否保留；整体与 token 青（#22D3EE）家族的偏差是否可接受（参考图偏天青，非 token 青——以用户图为准还是校回 token 色板，需 leader/用户裁决，QA 时标注）。
4. **边缘**：剪影平滑度（无生成图的抖动毛边）；鲸体间遮挡关系干净；无水印、无残留文字。
5. **图标规范**：1024 画板；圆角与 macOS continuous corner 视觉对齐（外层 rx≈186/820 与 DFH 图标一致或按参考图外框）；32px 以下可读性（四鲸回旋在小尺寸的辨识度，必要时出简化档）。
6. **工程**：SVG 单文件、defs/use 复用鲸形（四鲸=同一 path 旋转 4 次）、无外链资源；暗色 Dock 场景辨识度。
